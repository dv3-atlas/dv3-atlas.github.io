# ATLAS — 드래곤빌리지3 교배 조합 계산기

사이트: https://dv3-atlas.github.io/

드래곤빌리지3 플레이어를 위한 비공식 팬 제작 도구입니다. 목표 드래곤의 부모 조합과 확률, 부모로 자손 예측, 최단 교배 루트, 시도 횟수·모래시계 비용, 교배 타이머, 내 컬렉션을 한곳에서 볼 수 있습니다.

- 확률은 게임의 교배 절차(고정 확률종 우선 배정, 티어별 상한, 나머지 가중치 분배)를 재현한 이론값입니다.
- 보유 드래곤·타이머는 브라우저에만 저장되며 서버로 전송되지 않습니다.
- 게임 데이터와 일러스트의 권리는 하이브로(Highbrow)에 있습니다. 권리자의 요청이 있으면 즉시 삭제합니다.
